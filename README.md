## GitHub Pages entry point

This repository hosts the GitHub user site at [alexar76.github.io](https://alexar76.github.io/).
Its current homepage redirects to the factory landing at `modeldev.modelmarket.dev`.
The canonical ecosystem landing is the separate site linked above.
Project Pages such as `/aicom/` and `/helios/` are hosted by their respective repositories.

## Source of truth

Monorepo path: `scripts/github-io/` in [alexar76/aicom](https://github.com/alexar76/aicom).

The following command publishes the full generated site to this repository; it is separate from a README-only update:

```bash
# from the monorepo
./scripts/publish_github_io.sh
```
